11. Conclusion

This paper presented the complete BorrowScope pipeline as a unified system: five independent components connected by well-defined data formats, orchestrated by a single status bar button that automates the entire flow from source code to visual feedback. The analyzer extracts semantic type information into type-info.json (the central bridge), the macro uses it to instrument code with type-specific tracking calls (82 categories, zero heuristics), the runtime records 88 event types during execution (~75ns per event), the LSP provides real-time static analysis in parallel (<100ms per function), and the VS Code extension merges both perspectives into 11 interactive views with 9 divergence detectors.

The pipeline maintains three invariants end-to-end. First, zero heuristics: every decision from type classification through divergence detection is grounded in semantic resolution via compiler APIs, never in string matching or naming conventions. Second, zero cost when disabled: the track feature flag compiles all instrumentation to identity functions that the optimizer eliminates, allowing annotations to remain in the codebase permanently without affecting production builds. Third, graceful degradation: any component can be used independently (the LSP works without the runtime, the extension works without the macro), and the pipeline degrades to its component baselines rather than failing entirely when one stage encounters an error.

The ecosystem is validated by over 2,100 tests: 563 macro tests ensuring correct type-info dispatch, 775 runtime tests verifying event recording and zero-cost behavior, 107 LSP protocol tests confirming real-time analysis correctness, and 721 extension tests covering all visualizations, the merge layer, and the E2E orchestration. The pipeline delivers what no single component can provide alone: the breadth of static analysis (all paths, instant feedback, cross-function tracking) combined with the precision of runtime observation (actual ref counts, exact timing, observed drop order), merged into a unified visualization that highlights exactly where predictions and reality diverge. One click to see it all.

To the belief that understanding ownership should be as easy as clicking a button.
