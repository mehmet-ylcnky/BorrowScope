Technical White Papers & Documentation

BorrowScope is a research and development project exploring the boundaries of Rust ownership visualization. It spans five crates that form a pipeline from source code to visual feedback:

  • • borrowscope-runtime - Records 88 ownership event types during execution (borrows, moves, drops, Rc clones, async crossings)
  • • borrowscope-macro - Procedural macro that automatically instruments code using semantic type information from the analyzer
  • • borrowscope-analyzer - Static analysis tool that extracts type data via rust-analyzer's compiler APIs into type-info.json
  • • borrowscope-lsp - Language Server providing real-time ownership analysis (borrow scopes, conflicts, cross-function tracking, memory layout)
  • • borrowscope-vscode - VS Code extension with 11 interactive visualization views, inline decorations, and runtime-static merge

Together they combine static analysis (all paths, instant feedback) with runtime observation (one path, precise measurements) to make Rust's ownership system visible and understandable. This is not production-ready software - it is an R&D project exploring how far you can push Rust's compile-time and runtime introspection capabilities.
