3. How It Works

3.1 The #[trace_borrow] Attribute

The #[trace_borrow] attribute is an attribute procedural macro that transforms function definitions. When applied to a function, it:

  1. Parses the function's AST using syn
  2. Walks the function body to identify ownership operations
  3. Generates tracking calls for each operation
  4. Emits the transformed function using quote
// Input to macro
#[trace_borrow]
fn example(x: String) {
    let y = &x;
    println!("{}", y);
}

// Output from macro (conceptual)
fn example(x: String) {
    borrowscope_runtime::track_scope_enter("example");
    borrowscope_runtime::track_ownership("x", "String");
    let y = {
        let __tmp = &x;
        borrowscope_runtime::track_borrow("y", "x", BorrowKind::Immutable);
        __tmp
    };
    println!("{}", y);
    borrowscope_runtime::track_drop("y");
    borrowscope_runtime::track_drop("x");
    borrowscope_runtime::track_scope_exit("example");
}

3.2 Transformation Pipeline

TokenStream ──▶ syn::parse ──▶ ItemFn AST ──▶ Analyze Body ──▶ Generate Calls ──▶ quote! output

Stage 1: Parsing

The macro receives a TokenStream and converts it into a structured ItemFn AST containing the function signature, body, and attributes.

Stage 2: Analysis

The macro walks the AST to identify ownership-relevant patterns:

  • let x = ... — variable binding
  • &x or &mut x — borrow expressions
  • func(x) — function calls
  • Block boundaries — scope enter/exit

Stage 3: Code Generation

For each operation, the macro generates tracking calls using quote! and inserts them at the correct position.

3.3 Code Generation

// Inside the procedural macro
let var_name = &local.pat;
let tracking_call = quote! {
    borrowscope_runtime::track_ownership(stringify!(#var_name), OwnershipKind::Owned);
};
