8. Roadmap

Current Status

The macro is in active development. Current capabilities:

  • ✅ Basic #[trace_borrow] attribute
  • ✅ Variable binding tracking
  • ✅ Borrow expression detection
  • ✅ Scope enter/exit tracking
  • ✅ Integration with runtime

Phased Development

Following the strategy outlined in the Type Information Barrier whitepaper:

PhaseGoalStatus
Phase 1 ~95% coverage via enhanced heuristics + annotations In Progress
Phase 2 Validation tool (cargo borrowscope check) Planned
Phase 3 Full compiler integration (if demand warrants) Future

Near-Term Priorities

Based on battle test analysis:

  1. ERR-003 fix: Conservative wrapping for mutable borrows
  2. ERR-012 fix: Detect and skip trait declarations
  3. Annotation system: #[borrowscope(ffi=[...], unions=[...])]
  4. Tuple destructuring: Preserve pattern structure
