4. What Gets Instrumented

4.1 Variable Bindings

Every let statement is tracked:

let x = String::from("hello");  // track_ownership("x", "String")
let y = 42;                       // track_ownership("y", "i32")
let z = vec![1, 2, 3];            // track_ownership("z", "Vec")

4.2 Borrows and Moves

Reference creation and ownership transfers:

let r = &x;           // track_borrow("r", "x", Immutable)
let m = &mut x;       // track_borrow("m", "x", Mutable)
let owned = x;        // track_move("owned", "x")

4.3 Function Calls

Function calls that may transfer or borrow values:

consume(x);           // track_move to function parameter
borrow(&x);           // track_borrow for reference parameter
let r = produce();    // track_ownership for return value

4.4 Scope and Drops

Block boundaries and implicit drops:

{                              // track_scope_enter("block")
    let temp = String::new();  // track_ownership("temp")
}                              // track_drop("temp"), track_scope_exit("block")
