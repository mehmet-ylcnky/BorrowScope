Abstract

The borrowscope-runtime provides comprehensive tracking of Rust's ownership operations through an event-sourced architecture. However, manually instrumenting code with tracking calls is tedious, error-prone, and impractical for real-world codebases. This paper introduces borrowscope-macro, a procedural macro that automatically transforms Rust functions to emit ownership events without manual intervention.

The #[trace_borrow] attribute macro analyzes function bodies at compile-time, identifies ownership-relevant operations—variable bindings, borrows, moves, function calls, and scope exits—and injects the appropriate tracking calls. The transformation is transparent: instrumented code behaves identically to the original, with the addition of ownership event emission.

This paper explains how the macro works, what patterns it instruments, and how to use it effectively. We also discuss the macro's fundamental limitations arising from Rust's compilation model—procedural macros operate on syntax before type information is available—and preview the solutions explored in the upcoming Type Information Barrier whitepaper.

Together with the runtime library, borrowscope-macro enables practical ownership visualization for education, debugging, and research with minimal developer effort.
