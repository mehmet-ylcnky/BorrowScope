7. Limitations

The macro operates on syntax only—it cannot access type information. This fundamental constraint, explored in depth in the Type Information Barrier whitepaper, leads to specific limitations.

The Core Constraint

Procedural macros execute before type checking in Rust's compilation pipeline. The macro sees tokens and syntax, not types and semantics.

What the Macro Cannot Detect

PatternWhy It's HardImpact
Move vs Copy Requires knowing if type implements Copy May report moves for copies
FFI calls Cannot distinguish extern functions FFI boundaries not tracked
Trait methods Cannot resolve which impl applies Some method calls misclassified
Generic bounds Cannot see impl Trait constraints Wrapping may break bounds

Empirical Results

The Battle Test whitepaper validates these limitations empirically. Testing across 14,562 functions in five production codebases:

  • 80.5% pass rate — most patterns work correctly
  • Six error categories — all trace to type information barrier
  • Concentrated failures — two patterns cause 73% of errors

Mitigation Strategies

The theoretical paper proposes solutions including annotation systems, validation tools, and enhanced heuristics. The battle test data guides prioritization of these fixes.
