5. Usage Guide

5.1 Basic Usage

Add dependencies to Cargo.toml:

[dependencies]
borrowscope-macro = "0.1"
borrowscope-runtime = "0.1"

Annotate functions to trace:

use borrowscope_macro::trace_borrow;

#[trace_borrow]
fn my_function(data: String) -> usize {
    let len = data.len();
    len
}

Access the event stream:

use borrowscope_runtime::get_events;

fn main() {
    my_function(String::from("hello"));
    
    for event in get_events() {
        println!("{:?}", event);
    }
}

5.2 Configuration Options

The macro supports optional configuration:

// Trace with custom scope name
#[trace_borrow(name = "custom_scope")]
fn my_function() { }

// Disable drop tracking (reduces noise)
#[trace_borrow(track_drops = false)]
fn my_function() { }

5.3 Output Interpretation

Events are emitted in execution order:

ScopeEnter { name: "my_function", timestamp: 1001 }
VariableCreated { name: "data", type: "String", timestamp: 1002 }
BorrowCreated { borrower: "len", owner: "data", kind: Immutable, timestamp: 1003 }
VariableDropped { name: "data", timestamp: 1004 }
ScopeExit { name: "my_function", timestamp: 1005 }

These events feed into the runtime's graph construction algorithms, enabling visualization of ownership relationships over time.
