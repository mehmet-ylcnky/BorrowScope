Appendix B: Error Code Reference

Complete reference for all error codes identified during battle testing.

B.1 ERR-003: Mutable Borrow Conflicts

// Compiler error: cannot borrow `*data` as mutable more than once
// Trigger: Wrapping method calls on &mut references

// Problematic pattern:
fn example(data: &mut Vec<i32>) {
    track_call(data.push(1));  // Double borrow
}

// Root cause: Macro cannot detect &mut type
// Barrier section: §5.4 Type-Dependent Method Behavior

B.2 ERR-012: Trait Implementation Signature Mismatch

// Compiler error: method `poll` has an incompatible type for trait
// Trigger: Instrumenting trait impl methods

// Problematic pattern:
impl Future for MyFuture {
    #[trace_borrow]  // Changes signature
    fn poll(...) -> Poll<...> { }
}

// Root cause: Macro cannot distinguish trait decl from impl
// Barrier section: §4.1 The Fundamental Constraint

B.3 ERR-002: Tuple Destructuring

// Compiler error: mismatched types, expected tuple
// Trigger: Wrapping expressions assigned to tuple patterns

// Problematic pattern:
let (a, b) = track_return(get_pair());

// Root cause: Wrapper doesn't preserve tuple type
// Barrier section: §5.4 Type-Dependent Method Behavior

B.4 ERR-009: Self-Consuming Functions

// Compiler error: use of moved value
// Trigger: Wrapping calls to methods taking self by value

// Problematic pattern:
let result = track_call(builder.build());  // builder moved

// Root cause: Macro cannot detect self vs &self
// Barrier section: §5.4 Type-Dependent Method Behavior

B.5 ERR-014: Trait Method Declarations

// Compiler error: expected function body
// Trigger: Attempting to instrument bodyless declarations

// Problematic pattern:
trait Handler {
    #[trace_borrow]  // No body to instrument!
    fn handle(&self);
}

// Root cause: Macro applied to declaration, not definition
// Barrier section: §4.1 The Fundamental Constraint

B.6 ERR-008: Trait Bound Failures

// Compiler error: the trait bound `...` is not satisfied
// Trigger: Wrapping arguments with trait bounds

// Problematic pattern:
fn process(value: impl Into<String>) { }
process(track_arg("hello"));  // Wrapper breaks bound

// Root cause: Macro cannot see impl Trait bounds
// Barrier section: §5.4 Type-Dependent Method Behavior
