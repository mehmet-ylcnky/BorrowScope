7.2 Fix Strategies

ERR-003: Mutable Borrow Conflicts

Strategy: Conservative wrapping for method calls on potentially mutable references.

Rather than wrapping all method calls, the macro can use heuristics to identify likely mutable borrow scenarios:

  • Skip wrapping for common mutating methods: push, insert, remove, clear, extend
  • Skip wrapping when the receiver appears in a &mut pattern earlier
  • Use post-call tracking instead of wrapping: x.method(); track_after();

ERR-012: Trait Implementation Signature Mismatch

Strategy: Detect trait context and skip instrumentation for trait blocks.

The macro can track whether it's inside a trait block by examining the AST context: 

// In macro transformation logic:
if is_inside_trait_definition(item) {
    // Skip instrumentation - this is a declaration, not implementation
    return item.clone();
}
// Proceed with instrumentation for impl blocks

ERR-002: Tuple Destructuring

Strategy: Detect tuple patterns on the left-hand side and preserve return type.

When the macro sees let (a, b) = expr, it should either:

  • Skip wrapping the expression entirely
  • Use a wrapper that preserves tuple structure: track_tuple(expr)

ERR-009: Self-Consuming Functions

Strategy: Detect self (not &self) in method signatures and adjust wrapping.

Methods taking self by value consume ownership. The macro can detect this pattern in the function signature and use move-compatible tracking.

ERR-014: Trait Method Declarations

Strategy: Check for method body before attempting instrumentation.

Simple fix: if a function has no body (ends with ; instead of { ... }), skip instrumentation.

ERR-008: Trait Bound Failures

Strategy: Use transparent wrappers or skip wrapping for generic arguments.

This is the hardest to fix without type information. Potential approaches:

  • Detect impl Trait in parameter types and skip wrapping those args
  • Use identity wrappers that preserve the original type
  • Rely on the annotation system for edge cases
