Abstract

Rust's procedural macros operate under a fundamental architectural constraint: they execute during the early stages of compilation, before type inference and resolution have occurred. This "type blindness" means that a procedural macro transforming let data = Rc::new(RefCell::new(vec![1, 2, 3])); receives only raw tokens—it cannot determine that data has type Rc<RefCell<Vec<i32>>>, that Rc<T> is a reference-counted smart pointer, or that the inner RefCell<T> provides interior mutability. This limitation is not a bug but an intentional property of Rust's compilation model, designed to maintain determinism and enable parallel macro expansion.

This whitepaper presents borrowscope-analyzer, a static analysis tool that bridges this gap through a two-phase build strategy. The analyzer leverages rust-analyzer's published semantic analysis engine (ra_ap_* crates) to perform full type resolution on Rust source code as a pre-build step, extracting comprehensive type metadata into a structured JSON file that the #[trace_borrow] procedural macro can consume at expansion time. This decouples type analysis from macro expansion while working within—rather than against—Rust's compilation model.

The analyzer produces a rich output schema (v2.3) capturing: fully resolved type strings including generic parameters, trait implementation flags (Copy, Clone, Send, Sync, Drop, Future, Iterator) detected via impls_trait(), ADT classification through canonical module path matching (e.g., alloc::rc::Rc), and semantic initializer pattern classification across 78 distinct categories—from smart pointer constructors and interior mutability types to atomics, channels, and async primitives. A function-scoped disambiguation mechanism using declaration indices enables precise variable resolution even in the presence of shadowing.

The tool currently achieves semantic coverage for 36 of 109 ownership-related patterns (33%) used by the macro, with the remaining 73 patterns involving method calls on existing variables, standalone expressions, and self-borrow type inference. This paper documents a comprehensive roadmap organized into five implementation phases that would achieve 100% semantic coverage, eliminating all heuristic pattern matching from the macro within an estimated 19 hours of development effort. The complete BorrowScope pipeline—spanning static analysis, compile-time code transformation, and runtime event capture—demonstrates a practical approach to augmenting Rust's compilation model with pre-computed semantic information.
