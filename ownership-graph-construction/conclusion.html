8. Conclusion

This paper presented borrowscope-graph, a library that transforms flat runtime event streams into structured ownership graphs. The system addresses the fundamental limitation of event-based tracking: while events capture what happened, graphs capture how things relate.

The key contributions are:

  • A type system of 2 node kinds and 11 edge kinds that models the full spectrum of Rust's ownership relationships without information loss.
  • A single-pass O(n) construction algorithm with active borrow tracking that correctly terminates temporal edges on variable drop.
  • Two construction modes (batch and streaming) with a proven equivalence guarantee, enabling both post-hoc analysis and real-time visualization.
  • Incremental update operations (remove, merge) that maintain index consistency for interactive graph editing.
  • Seamless integration with borrowscope-runtime via from_runtime() for one-line graph construction from any instrumented program.

The graph structure serves as the foundation for higher-level analyses documented in companion papers: traversal algorithms and conflict detection (Paper 2), temporal queries and lifetime visualization (Paper 3), static-dynamic graph fusion (Paper 4), and multi-format export (Paper 5).

The implementation is available as part of the BorrowScope project, validated with 259 tests including property-based invariant verification, and benchmarked to confirm sub-millisecond construction times for typical program sizes.
