Abstract

Runtime ownership tracking in Rust produces flat event streams: chronological sequences of creation, borrow, move, and drop operations. While these streams capture every ownership operation faithfully, they lack the structural relationships needed to answer questions like "who borrows from this variable?", "what is the move chain for this value?", or "are there overlapping mutable borrows at this point in time?" This paper presents borrowscope-graph, a library that transforms flat event streams into structured, queryable ownership graphs that make these questions answerable in constant time.

The system defines a type system of 2 node kinds and 11 edge kinds that model the spectrum of Rust's ownership relationships, from basic borrows and moves to Rc/Arc clones, RefCell borrows, mutex locks, closure captures, and channel sends. Each edge kind carries semantic metadata specific to its relationship type: reference counts for clone edges, mutability flags for borrow edges, and capture modes for closure edges. This granularity ensures that no ownership information is lost during the transformation from events to graph.

A single-pass O(n) construction algorithm maps events to graph elements while tracking active borrows in a HashMap for correct edge termination when variables are dropped. Two construction modes are provided: batch processing via from_events() for post-hoc analysis, and streaming construction via GraphStream with update callbacks for real-time visualization. Both modes produce identical graphs, a property verified through dedicated equivalence tests.

The implementation is validated with 259 tests including property-based invariant verification using proptest, and benchmarked with Criterion on graphs with up to 100,000 events. Integration with borrowscope-runtime enables one-line graph construction from any instrumented Rust program, bridging the gap between runtime event capture and structural ownership analysis.
