Abstract

Runtime ownership tracking in Rust produces flat event streams: chronological sequences of creation, borrow, move, and drop operations. While these streams capture every ownership operation faithfully, they lack the structural relationships needed to answer questions like "who borrows from this variable?" or "what is the move chain for this value?" This paper presents borrowscope-graph, a library that transforms flat event streams into structured, queryable ownership graphs.

The system defines a type system of 2 node kinds and 11 edge kinds that model the full spectrum of Rust's ownership relationships, from basic borrows and moves to Rc/Arc clones, RefCell borrows, mutex locks, and closure captures. A single-pass O(n) construction algorithm maps events to graph elements while tracking active borrows for correct edge termination. Two construction modes are provided: batch processing for post-hoc analysis and streaming construction with callbacks for real-time visualization.

The implementation is validated with 259 tests including property-based invariant verification, and benchmarked on graphs with up to 100,000 events. Integration with the BorrowScope runtime enables one-line graph construction from any instrumented Rust program.
