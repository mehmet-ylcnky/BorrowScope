3. Construction Algorithm

3.1 Event-to-Graph Mapping

The construction algorithm processes events in a single pass, maintaining a mapping from runtime variable IDs to graph NodeIds. Each event type maps to a specific graph operation:

Event TypeGraph OperationResult
Event::Newadd_variable()New node created
Event::Borrowadd_borrow()Borrow edge from borrower to owner
Event::Moveadd_variable() + add_move()New node + move edge
Event::Dropmark_dropped() + end_edge()Node terminated, active borrows ended
Event::RcCloneadd_rc_clone()Clone edge with strong_count
Event::ArcCloneadd_arc_clone()Clone edge with strong_count
Event::ClosureCaptureadd_capture()Capture edge with mode
Event::FnEnteradd_scope()Scope node created
Event::FnExitmark_dropped()Scope node terminated
Event::RegionEnteradd_scope()Block scope node
Event::RegionExitmark_dropped()Block scope terminated

Events that do not create ownership relationships (e.g., LoopIteration, BinaryOp) are ignored during graph construction. They remain in the event stream for other analysis purposes but do not produce graph elements.

3.2 Active Borrow Tracking

The critical challenge in graph construction is determining when borrow edges end. A borrow begins when a Borrow event is recorded, but it ends implicitly when the borrower is dropped. The algorithm maintains a HashMap<String, Vec<EdgeId>> that maps each variable's runtime ID to its active borrow edges: 

let mut active_borrows: HashMap<String, Vec<EdgeId>> = HashMap::new();

// On Borrow event: record the edge as active
let eid = graph.add_borrow(borrower, owner, mutable, timestamp);
active_borrows.entry(borrower_id.clone()).or_default().push(eid);

// On Drop event: end all borrows held by this variable
if let Some(edges) = active_borrows.remove(&var_id) {
    for eid in edges {
        graph.end_edge(eid, timestamp);
    }
}

This approach correctly handles multiple simultaneous borrows from the same variable (e.g., a variable that borrows from two different owners) and ensures that all borrow edges receive an ended_at timestamp when the borrower is dropped.

3.3 Variable ID Resolution

The runtime assigns each variable a unique string ID in the format "name_counter" (e.g., "x_0", "r_1"). The construction algorithm maintains a HashMap<String, NodeId> that maps these runtime IDs to graph NodeIds. This mapping is essential for correlating events: when a Borrow event references owner_id: "x_0", the algorithm looks up the corresponding NodeId to create the edge.

Variable shadowing is handled naturally: each declaration creates a new runtime ID (e.g., "x_0" and "x_1" for two declarations of x), so they map to distinct graph nodes. The name index in the graph stores both under the name "x", allowing queries like "find all variables named x" to return both.

3.4 Complexity Analysis

The construction algorithm is O(n) in the number of events, with constant-factor overhead per event:

  • Node creation: O(1) amortized (Vec push + HashMap insert)
  • Edge creation: O(1) amortized (Vec push + two HashMap inserts for adjacency)
  • Drop processing: O(k) where k is the number of active borrows on the dropped variable (typically 0-3)
  • ID lookup: O(1) (HashMap get)

Total construction time for n events is O(n) with a small constant factor dominated by HashMap operations. Memory usage is O(n + m) where n is the number of nodes and m is the number of edges.

3.5 The Complete Algorithm

pub fn from_events(events: &[Event]) -> OwnershipGraph {
    let mut graph = OwnershipGraph::new();
    let mut var_ids: HashMap<String, NodeId> = HashMap::new();
    let mut active_borrows: HashMap<String, Vec<EdgeId>> = HashMap::new();

    for event in events {
        match event {
            Event::New { var_id, var_name, type_name, timestamp, .. } => {
                let id = graph.add_variable(var_name, type_name, *timestamp);
                var_ids.insert(var_id.clone(), id);
            }
            Event::Borrow { borrower_id, owner_id, mutable, timestamp, .. } => {
                if let (Some(&borrower), Some(&owner)) =
                    (var_ids.get(borrower_id), var_ids.get(owner_id))
                {
                    let eid = graph.add_borrow(borrower, owner, *mutable, *timestamp);
                    active_borrows.entry(borrower_id.clone()).or_default().push(eid);
                }
            }
            Event::Drop { var_id, timestamp, .. } => {
                if let Some(&id) = var_ids.get(var_id) {
                    graph.mark_dropped(id, *timestamp);
                    if let Some(edges) = active_borrows.remove(var_id) {
                        for eid in edges {
                            graph.end_edge(eid, *timestamp);
                        }
                    }
                }
            }
            Event::RcClone { var_id, var_name, source_id, strong_count, timestamp, .. } => {
                // Create node if not exists, then add clone edge
                let clone_id = *var_ids.get(var_id).unwrap_or(
                    &graph.add_variable(var_name, "Rc", *timestamp));
                if let Some(&src) = var_ids.get(source_id) {
                    graph.add_rc_clone(clone_id, src, *strong_count as u32, *timestamp);
                }
            }
            // ... remaining event types follow the same pattern
            _ => {} // Events without ownership relationships are skipped
        }
    }
    graph
}
