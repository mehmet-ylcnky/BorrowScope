7.2 Property-Based Invariants

Six graph invariants are verified using proptest with randomly generated graphs:

  • Every edge references valid node IDs (no dangling references)
  • DFS visits each reachable node exactly once (no duplicates)
  • Node count is monotonically increasing after additions
  • JSON round-trip preserves node and edge counts
  • Connected components partition all nodes (no node left out)
  • BFS distances are monotonically non-decreasing

Each property test runs 256 cases with shrinking on failure, ensuring that any invariant violation produces a minimal reproducible example.

7.3 Battle Test Validation

The graph construction is validated against real event streams captured from instrumented Rust programs. The examples/macro-integration/events.json fixture contains 117 events from a program exercising Rc, RefCell, closures, and method calls. The graph builds without panic and passes validation: 

let events: Vec<Event> = serde_json::from_str(&fixture_json).unwrap();
let graph = OwnershipGraph::from_events(&events);
assert!(graph.node_count() > 0);
assert!(is_valid(&graph));
