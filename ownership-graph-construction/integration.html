6. Runtime Integration

6.1 One-Line Graph Construction

The primary integration point is OwnershipGraph::from_runtime(), which reads the global event buffer from borrowscope-runtime and constructs the graph in a single call: 

use borrowscope_runtime::*;
use borrowscope_graph::OwnershipGraph;

fn main() {
    reset();
    my_instrumented_function();

    // One line to get the complete ownership graph
    let graph = OwnershipGraph::from_runtime();

    println!("Nodes: {}, Edges: {}", graph.node_count(), graph.edge_count());
}

This is the recommended entry point for most users. It calls get_events() internally and delegates to from_events(). The graph is constructed after the instrumented code has finished executing, so there is zero overhead during the program's actual execution.

6.2 Filtered Construction

For large programs where only a subset of variables is of interest, filtered construction avoids building graph nodes for irrelevant events: 

// Only events for a specific variable
let graph = OwnershipGraph::from_runtime_for_var("data");

// Custom filter: only New and Borrow events
let graph = OwnershipGraph::from_runtime_filtered(|e| {
    matches!(e, Event::New { .. } | Event::Borrow { .. })
});

from_runtime_for_var() filters events by variable name, including borrows where the variable is the owner. This produces a focused subgraph centered on a single variable and its relationships.

6.3 Dependency Architecture

The crate dependency flows in one direction: borrowscope-graph depends on borrowscope-runtime (for the Event type and get_events() function). There is no reverse dependency. Users add both crates to their Cargo.toml: 

# Cargo.toml
[dependencies]
borrowscope-macro = "0.2"
borrowscope-runtime = { version = "0.1", features = ["track"] }
borrowscope-graph = "0.1"

This architecture avoids circular dependencies while keeping the integration seamless. The graph crate is entirely optional: projects that only need event tracking can omit it with no compile-time or runtime cost.

6.4 End-to-End Workflow

The complete workflow from instrumentation to graph visualization: 

use borrowscope_macro::trace_borrow;
use borrowscope_runtime::*;
use borrowscope_graph::{OwnershipGraph, export};

#[trace_borrow]
fn process_data() {
    let data = vec![1, 2, 3];
    let r = &data;
    println!("{:?}", r);
}

fn main() {
    reset();
    process_data();

    let graph = OwnershipGraph::from_runtime();

    // Export to Graphviz DOT for visualization
    let dot = export::to_dot(&graph, &export::DotOptions::default());
    std::fs::write("ownership.dot", dot).unwrap();

    // Export to D3.js for web visualization
    let d3 = export::to_d3_json(&graph).unwrap();
    std::fs::write("ownership.json", d3).unwrap();
}
