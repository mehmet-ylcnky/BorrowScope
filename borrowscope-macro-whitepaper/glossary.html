Appendix A: Glossary

AST (Abstract Syntax Tree): A tree representation of the syntactic structure of source code, where each node represents a construct in the language grammar.

DefId (Definition Identifier): A unique identifier in rustc that refers to a specific definition (function, type, static, etc.) in the crate being compiled.

HIR (High-level Intermediate Representation): Rustc’s desugared AST that includes resolved names and is used for type checking. HIR preserves the structure of the source code while removing syntactic sugar.

MIR (Mid-level Intermediate Representation): Rustc’s control-flow graph representation used for borrow checking, optimization, and code generation. MIR makes all operations explicit, including drops and moves.

Proc Macro (Procedural Macro): A Rust macro implemented as a function that receives and produces token streams, enabling arbitrary code transformation at compile time.

THIR (Typed High-level Intermediate Representation): An intermediate representation between HIR and MIR that includes full type information for all expressions.

TokenStream: The input and output type for procedural macros, representing a sequence of tokens (identifiers, literals, punctuation, and delimited groups).

TyCtxt (Type Context): Rustc’s central data structure containing all type information for a crate, providing methods to query types, resolve definitions, and access semantic information.

Type Inference: The compiler’s process of determining the types of expressions that lack explicit type annotations, based on how values are used.

Name Resolution: The compiler phase that connects each use of an identifier to its definition, determining what each name in the program refers to.
