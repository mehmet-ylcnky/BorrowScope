Abstract

Rust's ownership system is one of its most distinctive features, promising memory safety without garbage collection through compile-time analysis. However, this compile-time nature makes the runtime behavior of ownership operations—transfers, borrows, and drops—completely invisible to developers and researchers. This invisibility creates a significant gap between the theoretical understanding of ownership semantics and their practical runtime manifestations.

This paper presents borrowscope-runtime, a novel event-sourced instrumentation system that captures comprehensive ownership operations at runtime with minimal performance overhead. Our approach introduces a taxonomy of 20+ event types covering all aspects of Rust's ownership model, from basic variable creation and borrowing to complex patterns involving smart pointers, interior mutability, and unsafe code boundaries.

The system achieves true zero-cost abstraction through conditional compilation, imposing approximately 75 nanoseconds overhead per operation when enabled, while compiling to complete no-ops when disabled. Key technical contributions include: (1) a thread-safe global tracker with atomic timestamp generation, (2) comprehensive event taxonomy representing all ownership patterns, (3) RAII-based automatic instrumentation, and (4) efficient ownership graph reconstruction algorithms.

borrowscope-runtime enables new applications in education, debugging, performance analysis, and programming language research, providing a comprehensive runtime view of Rust's ownership system. The system has been validated through extensive testing to demonstrate its effectiveness as both a practical development tool and a research platform.
