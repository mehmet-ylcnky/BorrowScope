Abstract

Rust's procedural macros operate before type checking occurs, receiving only raw tokens without access to resolved types, trait implementations, or semantic information. This architectural constraint, inherent to Rust's compilation model, forces procedural macros that need type-aware behavior to rely on fragile string-matching heuristics. This paper presents BorrowScope, a complete system that eliminates all such heuristics through a two-phase build strategy: a pre-build static analyzer leveraging rust-analyzer's semantic engine extracts comprehensive type metadata into a JSON file, which the procedural macro then consumes at compile time for fully semantic dispatch.

The system achieves semantic coverage across all 109 ownership-related patterns (up from 33% reported in the initial whitepaper), with zero string-matching heuristics remaining in the macro. The analyzer produces a rich output schema (v3.0) with 81 per-variable fields, 10 method call metadata fields, and 22 project-wide analysis maps, covering trait implementations, ADT classification, method call resolution, self-borrow inference, closure captures, await points, borrow spans, and unsafe operations.

During development, an API gap was identified in rust-analyzer's public interface: raw pointer mutability (*mut T vs *const T) was not queryable. This was resolved through an upstream contribution (PR #21835, merged April 2026), adding is_mutable_raw_ptr() and as_raw_ptr() to hir::Type, demonstrating that building tools on rust-analyzer drives improvements to the platform itself.

The runtime component captures 88 distinct event types covering the full Rust ownership model: smart pointers, interior mutability, concurrency primitives, unsafe operations, async/await, control flow, and more. The complete system is validated through battle tests on real-world projects: ripgrep (287 tests pass with instrumented source), the lru crate (107 events tracked), and the uuid crate (88 events tracked), all requiring zero modifications to the macro or analyzer.

The BorrowScope pipeline, spanning static analysis, compile-time code transformation, and runtime event capture, demonstrates a practical, production-ready approach to augmenting Rust's compilation model with pre-computed semantic information, applicable beyond ownership visualization to any domain where procedural macros require type awareness.
